# **App Name**: VenueVista

## Core Features:

- Room Browser: Browse available conference rooms and time slots, filtering by capacity and available amenities.
- Room Booker: Select a room and book it for a specific duration; auto-adjust booking time by snapping to standard meeting times.
- Booking History: View personal booking history with upcoming and past reservations in a convenient calendar format.
- Reservation Manager: Cancel existing reservations with a single click, providing optional reason for cancellation.
- Smart Suggest: Suggest the most suitable meeting rooms to users as a helpful tool, by cross-examining details provided in meeting invitations with room specs.
- Limited Room Count: Room count shall be fixed to six.

## Style Guidelines:

- Primary color: Professional blue (#3498db), providing a sense of trust and reliability.
- Background color: Light gray (#f0f2f5), offering a clean and modern aesthetic. 
- Accent color: Sky blue (#85c1e9) used for interactive elements and highlights, complementing the primary color.
- Body and headline font: 'Inter', a sans-serif font offering excellent readability and a clean, modern look.
- Use consistent, professional line icons representing various functionalities like room features, time slots, and booking management.
- Maintain a clean and intuitive layout, ensuring ease of navigation and a user-friendly experience for all IT employees.
- Use subtle transitions and animations for a polished and engaging user interface.
